# Security Policy

## Supported Versions

We release patches and security fixes for the latest active release versions of **Viral Thread Generator**.

| Version | Supported          |
| :---    | :---:              |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security of **Viral Thread Generator** seriously. If you discover a security vulnerability or security-sensitive bug, please report it privately rather than opening a public issue.

### How to Report
- **Email**: Send detailed information about the vulnerability to [support@viralthreadgenerator.com](mailto:support@viralthreadgenerator.com).
- **GitHub Advisory**: Alternatively, you can use the [GitHub Private Vulnerability Reporting](https://github.com/agnivon/viral_thread_generator/security/advisories/new) feature.

### What to Include in Your Report
Please provide as much information as possible to help us triage and resolve the issue quickly:
- A description of the vulnerability and its potential impact.
- Clear steps to reproduce the issue or proof-of-concept code.
- Affected components (e.g. Next.js actions, Convex endpoints, auth flows, turnstile validation).
- Any suggested mitigations or patches.

### Our Commitment
- **Acknowledgment**: We will acknowledge receipt of your vulnerability report within **48 hours**.
- **Assessment**: We will evaluate the impact and keep you informed of our progress.
- **Resolution**: Once a fix is verified, we will publish a patch release and credit you (unless you prefer to remain anonymous).

Please do not publicly disclose the vulnerability until we have had adequate time to address and patch it.
